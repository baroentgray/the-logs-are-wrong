# UI_SIGNALS

Критическое событие имеет минимум звук и свет/движение.

| Событие | Обязательный сигнал |
|---|---|
| Объект поступил | ворота/ролики + лампа входа |
| 15 сек. до автоподачи | жёлтая лампа + двигатель |
| 5 сек. | красная лампа + ускоренный сигнал |
| Автоподача | удар и движение толкателя |
| Маршрут | физическое положение стрелки |
| Вход в `QUEUED_FOR_SAW` | захват стопором + механический щелчок + лампа пилы; это точка невозврата |
| Процедура | видимый предмет и короткая обратная связь |
| Затор | звук остановки + красная лампа |
| Продукция | табло квоты + счётчик |
| Списание | физический маршрут в отстойник, без подтверждения диагноза |
| `SERVICE_REQUESTED` | отдельный звонок + лампа отстойника |
| `OVERDUE` | усиленный звонок и беспокойство |
| `INCIDENT` | причинная реакция, неотличимость от бага запрещена |

## Правила

- Отстойник не раскрывает число опасных объектов.
- Ритуал до сигнала не имеет эффекта.
- UI не подтверждает диагноз до теста.
- Debug UI является отдельным отключаемым слоем.
